This directory is the versioned interaction contract for the Community Intelligence local web product. It defines hierarchy, navigation, evidence access and capability states before visual polish. It does not contain production analytics, final copy or a substitute for implementation tests.

Open `community-intelligence-wireframe.html` in a browser to move through all seven views. `LOW_FIDELITY_WIREFRAME.md` explains the cross-page rules and the intent of each view. The seven SVG files are static previews that render directly on GitHub and can be cited in review discussions.

The production interface may refine spacing, typography and responsive behavior, but it must preserve these contracts: important claims open supporting evidence; unavailable data is distinct from an unimplemented method; synthetic and imported sources are visible; human review remains explicit; message volume is never presented as a quality score; statistical association is never presented as causation.
